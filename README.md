# HTML Lab Assignment 2 - Solutions

Practical solutions for Web Technology / HTML lab. Each practical is in its own folder with runnable HTML files.

## Practical List

- **Practical 1 - Semantic College Page**: Create a department webpage using HTML5 semantic elements such as <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>.
- **Practical 2 - Hyperlinks and Images**: Create a tourism webpage containing images and different types of hyperlinks.
- **Practical 3 - HTML Lists**: Demonstrate unordered, ordered and description lists.
- **Practical 4 - Student Timetable**: Design a timetable using HTML tables and demonstrate rowspan and colspan.
- **Practical 5 - Student Registration Form**: Create a student registration form with common HTML form controls.
- **Practical 6 - HTML5 Input Types**: Demonstrate modern HTML5 input types.
- **Practical 7 - HTML5 Form Validation**: Create a form using built-in HTML5 validation attributes.
- **Practical 8 - Multimedia Webpage**: Create an e-learning webpage containing audio and video.
- **Practical 9 - External Content Using <iframe>**: Demonstrate embedding another webpage using an accessible iframe.
- **Practical 10 - Complete HTML5 Mini Project**: Develop a complete structured College Department website integrating semantic HTML, navigation, images, lists, tables, forms, validation and multimedia.

## How to run

Open each practical's `index.html` in any browser. Media files (images, audio, video) referenced in some practicals must be placed in the same folder as the HTML file.
